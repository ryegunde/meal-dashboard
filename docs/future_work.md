# Future Work

The **Meal Pipeline Planner** is a powerful tool for meal management, but there are several areas for potential improvement and expansion as the project evolves beyond Phase 1.

## Phase 2: Advanced Simulation & Logic

-   **Time-Aware Simulation**: Improve the engine to account for meal times (e.g., Breakfast vs. Dinner) and preparation durations more accurately.
-   **Preparation Reminders**: Implement a notification system or a dedicated "Prep Today" dashboard to alert users when a stage transition is required (e.g., "Season the chicken tomorrow").
-   **Stage Auto-Progression**: Allow inventory items to automatically move through stages based on time (e.g., Fridge -> Seasoned), with optional user confirmation.

## UI/UX Enhancements

-   **Rich Aesthetics**: Implement more vibrant color palettes, dark mode support, and smooth micro-animations to enhance the user experience.
-   **Mobile Optimization**: Improve responsiveness for a more seamless experience on smartphones and tablets.
-   **Drag-and-Drop Scheduling**: Allow users to drag recipes onto the calendar for easier meal planning.
-   **Enhanced Visuals**: Use charts or progress bars to visualize inventory levels and prep progress.

## New Features

-   **Shopping List Generation**: Automatically generate a shopping list based on scheduled meals and current inventory deficits.
-   **Nutritional Tracking**: Integration with nutritional APIs to track macros and calories for each meal.
-   **Recipe Imports**: Allow users to import recipes from external URLs or meal planning formats.
-   **Multi-User Sync**: Add backend support to allow multiple users to collaborate on the same meal plan.

## Technical Debt & Optimizations

-   **Component Refactoring**: Transition from vanilla JavaScript to a more structured framework (e.g., React or Vue) to improve maintainability and scalability.
-   **Unit Testing**: Expand the test suite to include unit tests for individual functions in the simulation engine.
-   **Accessibility (a11y)**: Ensure the application is fully accessible, following WCAG guidelines (e.g., aria-labels, keyboard navigation).
