# Project Documentation

Welcome to the **Meal Pipeline Planner** documentation. This directory contains in-depth information about the project's architecture, deployment, testing, and future roadmap.

## Documentation Index

1.  **[Architecture & Design](architecture.md)**: Overview of the project's structure, technology stack, and core logic.
2.  **[Deployment](deployment.md)**: Instructions on how to deploy the application to GitHub Pages.
3.  **[Testing](testing.md)**: Details on the automated testing suite using Playwright.
4.  **[Future Work](future_work.md)**: Roadmap and potential improvements for the project.

## Quick Start for Developers/Agents

-   **Development**: Run `npm run dev` to start a local server at `http://localhost:8080`.
-   **Testing**: Run `npm test` to execute the Playwright test suite.
-   **CI/CD**: Check `.github/workflows/playwright.yml` for the CI configuration.
